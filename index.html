AWS Spatial & Data Pipeline Architecture

Nepal MapIt demonstrates an end-to-end cloud spatial architecture conforming to AWS Best Practices for modern location applications:

🗺️ Amazon Location Service

Provides vector map rendering styles, Place Index geocoding for Nepal addresses, and reverse-geocoding coordinates.

🗄️ Amazon S3 + Apache Iceberg

Scalable storage tier holding spatial GeoJSON features structured in Apache Iceberg table format for schema evolution and partition pruning.

⚡ Amazon Athena

Serverless SQL queries over Iceberg tables on S3, filtering 2,876+ features by bounding box, city, and category tags with sub-second performance.

🚀 AWS Amplify / S3 Website

Zero-cold-start edge delivery of static assets with global CDN caching and automatic HTTPS security.
